VirtualBox Installation and Kali Linux Network Configuration

Download and install VirtualBox: I downloaded the latest version of Oracle VM VirtualBox and successfully installed it on my computer.

Download Kali Linux: I downloaded Kali Linux 2026 as a virtual machine image in preparation for setting up my cybersecurity lab environment.

Configure the VirtualBox network: Before importing and starting Kali Linux, I configured the virtual machine's network adapter to use NAT Network. I configured the network settings as follows:

IP address: 10.0.0.2

Default gateway: 10.0.0.1

DNS server: 8.8.8.8

Import and launch Kali Linux: I opened the extracted Kali Linux virtual machine image in VirtualBox and launched the virtual machine. After logging in with the default password, I proceeded to configure the network settings within Kali Linux.

Configure the Kali Linux network settings: Inside Kali Linux, I configured the network connection to use NAT Network and entered the same network settings:

IP address: 10.0.0.2

Default gateway: 10.0.0.1

DNS server: 8.8.8.8
